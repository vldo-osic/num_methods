Лабораторная работа по численным методам, выполненная с помощью TypeScript + React. Первая часть позволяет генерировать различные матрицы и вычислять решение с помощью методов Гаусса и Томаса. Вторая часть строит график заданной функции с помошбю Nivo и Mathjax, и при клике на предполагаемое решение на графике находит точное решение с помощью метода простой итерации.
